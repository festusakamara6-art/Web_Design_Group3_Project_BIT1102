# SaloneTech Hub - DCOMP 204 Final Project

Multi-page responsive website (HTML5, CSS3, JavaScript).

## Pages
index.html (Home), about.html, services.html, estimator.html, team.html, contact.html

## Shared files
- style.css - styling, responsive rules, dark mode
- script.js - menu, theme, counters, FAQ, service filter, estimator, form validation

## Run locally
Open index.html in a browser.

## Deploy
GitHub: Settings > Pages > Deploy from branch > main / root.
